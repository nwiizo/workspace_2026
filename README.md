# workspace_2026

2026年のワークスペースリポジトリ

## ディレクトリ構成

| ディレクトリ | 説明 |
|-------------|------|
| `blogs/` | ブログ記事の執筆・レビュー（Claude Codeコマンド付き） |
| `infrastructure/` | インフラ検証・セキュリティデモ |
| `samples/` | 小規模なサンプルコード・学習用 |
| `tools/` | ツール開発・ブログ記事の検証コード |

## blogs/

ブログ記事の執筆・レビューワークフロー

```
blogs/
├── .claude/
│   ├── agents/      # サブエージェント
│   ├── commands/    # カスタムコマンド（/full-review等）
│   ├── docs/        # ドキュメント
│   └── skills/      # スキル
└── CLAUDE.md        # プロジェクトガイド
```

## tools/

ブログ記事の検証コードやツール開発

- Rustプロジェクト
- Dockerビルド最適化
- MCP関連ツール
- コード分析ツール

## infrastructure/

インフラ関連の検証・デモ

- セキュリティ検証（WAF, コンテナセキュリティ）
- PostgreSQL活用
- モニタリング

## samples/

小規模なサンプルコード

- 言語学習用コード
- ライブラリ検証
- プロトタイプ
