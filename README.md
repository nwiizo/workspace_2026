## 自分を知る

### 強みと特性

- **ストレングスファインダー**：収集心、最上思考、内省、目的志向、戦略性
- **MBTI**：討論者型 (ENTP) - 外向型、直観型、思考型、知覚型

### 信念

**自分にはできると信じる。なんでもできる。なんにでもなれる。そのうえでエンジニアを選んでいる。**

この選択は消去法ではない。無限の可能性の中から、自分の意志でエンジニアリングを選んだ。困難に直面しても「できない」とは思わない。「まだできていないだけ」と考える。

### 限界の受容と環境設計

**私は全ての環境で完璧に活躍できるほど優秀ではない。これを受け入れる。だから環境を自分で作る。**

活躍しやすい環境の条件：

- **ゴールが明確であること**
- **失敗するサイクルを回しやすいこと**
- **自律性があること**

この条件が揃わない環境では**期待値をコントロールする**。「どこでも活躍できる人」より「この領域では誰にも負けない人」を目指す。

## 原則

### 仕事の姿勢

- 「やらなくては」ではなく「やると決める」
- 「全部できる」ではなく「なんでもできるが、全部はやらない」
- やる気の有無に関わらず、まず行動を起こす。モチベーションは行動から生まれる
- 権力を握らない。権力の外から眺める立場を維持する
- 認められようとしない。評価は死んだ後に決まる
- 競争を避ける。始まる前から勝負が決まっていることをやる

### 学びの姿勢

- 好奇心が刺激されることのみをやり続ける。自分に嘘をつかない
- わかるより、わからないことを知る方が価値がある
- 過去に学んだことを手放す勇気を持つ（アンラーン）
- 「自分が正しい」という前提を疑う

### コミュニケーション

**目的は「伝えること」ではなく「相手を動かすこと」。伝わらなければ意味がない。動かせなければ価値がない。**

- 聞く側に回る。知識は話す方から聞く方に流れている
- 言葉ではなくモデルを見る。発言の背後にある思考を理解する
- 人を見ない。インセンティブと構造を見る

### 人間関係

**顧客やフォロワーではなく、ファンを作る。**

- 一貫性を持つ
- 弱さを見せる
- 相手の成功を本気で喜ぶ
- 期待を超える
- 長期で考える

## 技術戦略

### フォーカス：Rust × 分散システム × AIエージェント基盤

**Rustを軸とした専門性の深化と、AIエージェントが良いコードを出すシステムの構築に注力する。**

### Rust

- コンパイラ内部（rustc、MIR、HIR、借用チェッカー）の理解
- rust-lang/rustへのコントリビュート
- 実用的なCLIツール・ライブラリの作成と公開（毎月1つ以上）

### 分散システム

- 基礎理論の体系的学習（Raft、Paxos、CRDTなど）
- 既存システム（etcd、TiKVなど）のコードリーディング
- 論文・書籍のレビューをブログに蓄積

### AIエージェント基盤

**AIエージェントがどう使われても良いコードが出るシステムを作る側に立つ。**

- AIの「ユーザー」ではなく「インフラ」になる
- AIの出力品質を決めるのはシステム設計。プロンプトより環境・制約・フィードバックループ
- 「AIが間違えても大丈夫」な仕組みを作る

**AIの知性は「ギザギザ」**。ある領域では驚異的、別の領域では驚くようなミスをする。システム設計者の仕事は、このギザギザを滑らかにすること。

| 設計思想 | 制御の主体 |
| --- | --- |
| **AI Agent with Human** | AIがワークフローを制御し、必要なタイミングで人を呼び出す |
| **Human with AI tools** | 人がワークフローを制御し、必要なタイミングでAIを呼び出す |

**スケールするのは前者**。私が作るシステムは「AI Agent with Human」を志向する。

ツールは変わる。しかし以下は変わらない：

- 基礎スキルを手放さない
- 深い理解が必要な領域ではAIに頼らない
- AIの限界を体感し、システム設計に活かす

## 働き方

### 生産性

**「たくさん働くこと」ではなく「少ない時間で大きな成果を出すこと」。**

- 午前中は「攻め」の時間（創造的な仕事）、午後は「守り」の時間（レビュー、ミーティング）
- 会議は最後の手段。非同期で済むことを同期でやらない
- 「やらないことリスト」を持つ

### 休息

- 休憩中にスマホを見ない
- 散歩は最高の休息
- 週末は本当に休む

### リモートワーク

- 通勤時間ゼロを学習・運動・睡眠に投資（年間500時間以上の差）
- 境界線を引く。終業時刻を決め、PCを閉じる
- 孤立を避ける。意識的に人と話す機会を作る

## 土台

### 健康

**健康は「あったらいいもの」ではなく「すべての土台」。**

- **運動**：週3回以上を非交渉事項として確保
- **食事**：一汁一菜、朝をしっかり昼を軽く、タンパク質を意識
- **睡眠**：睡眠時間を削って作業しない。睡眠負債は複利で蓄積する
- **メンタル**：孤独を感じたら人に会う。「なんとなく調子が悪い」を無視しない

### 資産

**幸福の構成要素：良い友人、良い対話、本、健康、移動。これで全部だ。**

- ものを持たない。選択肢を減らす
- 収入より支出が少なければ富は増える
- 投資して忘れる。長期的視点
- 金で買えないものに投資する（健康、人間関係、経験、スキル）

### 読書

**「技術書だけ読んでいると、技術書が読めなくなる」**

- 年間100冊（月8〜9冊）
- 技術書60冊、非技術書40冊のバランス
- 読んだ本は必ずアウトプットする

## 人格

### 魅力

**人は「何を言ったか」より「誰が言ったか」で判断する。**

- 感謝を言葉にする
- 愛嬌は戦略
- 成功は分かち合い、失敗は引き受ける

### 謙虚さ

- 調子に乗らない。成功を誇示しない
- 努力や苦労を適度に開示する
- 実力を磨き続ける。これが最強の嫉妬対策

### 自己との向き合い方

- 過度な自己否定は傲慢の裏返し
- 謝罪は素早く、言い訳は短く
- 変化を恐れない。去年の自分と意見が違っていい
