# blogs/

ブログ記事の執筆・レビュー用ディレクトリ

## 使い方

1. 記事を `blog.md` として作成
2. `/full-review blog.md コラム` または `/full-review blog.md 技術` でレビュー実行
3. レビュー結果を確認して修正

## ディレクトリ構成

```
blogs/
├── .claude/
│   ├── agents/      # サブエージェント定義
│   ├── commands/    # カスタムコマンド（/full-review等）
│   ├── docs/        # 参考ドキュメント
│   └── skills/      # スキル定義
├── CLAUDE.md        # Claude Codeへの指示
└── README.md
```

## 記事タイプ

- **コラム**: エッセイ、考察、意見記事
- **技術**: チュートリアル、ハウツー、技術解説

## 文章ルール

- 「です・ます」調で統一
- 見出しは `##` と `###` のみ使用
- 段落は3-5文で構成
- 80%の完成度で公開を推奨
