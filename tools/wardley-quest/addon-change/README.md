# Change Leadership Quest

[Strategic Evolution Quest](../) のアドオンシナリオ

モダナイゼーションを成功に導く組織変革リーダーシップを学ぶRPG。AMET（Architecture Modernization Enabling Team）、組織の準備状態評価、学習文化の醸成などを実践します。

## 前提

**単体でもプレイ可能です。** [Strategic Evolution Quest](../) をプレイ済みだとより深く理解できます。

## 学べる概念

### AMET（Architecture Modernization Enabling Team）

Nick Tuneが提唱する、モダナイゼーションを推進する専門チームの設計・運営手法。

- **役割定義**: 変革を牽引する専門チームの構成と責任範囲
- **支援モデル**: ストリームアラインドチームへの支援（コーチング、ペアリング、コンサルティング）
- **成功基準**: 自立化を目指した段階的な撤退戦略

### 組織変革の原則

- **抵抗への対処**: 技術者・経営層・ステークホルダーの抵抗パターンと対処法
- **学習文化の醸成**: 心理的安全性と継続的改善の文化づくり
- **変革の測定**: DORA メトリクスを活用した進捗の可視化
- **測定の副作用への警戒**: キャンベルの法則（測定可能にすることで目的が歪む）を意識し、表面的指標と本質的改善を区別する

### 失敗学と組織学習

変革における失敗を学習機会として活用：

- **良い失敗と悪い失敗の区別**: 挑戦的な失敗と怠慢な失敗を分けて評価
- **失敗情報の共有**: 失敗を隠さず、組織全体で学ぶ文化
- **リスク取引と挑戦文化**: 適切なリスクを取る判断力の養成

### 持続可能な変革

変革推進者の燃え尽きを防ぐ：

- **体力の再定義**: AI協働時代における新しい「体力」の概念（判断力、創造性、メタ認知の持続）
- **認知負荷の管理**: 変革リーダーの認知負荷を意識的にコントロール
- **長期戦の覚悟**: 組織変革は短期決戦ではなく、持続可能なペースで進める

### 変革パターン

組織変革に有効なパターンを状況に応じて適用：

- **アーリーアダプター**: 最初の支持者を見つける
- **スモールサクセス**: 小さな成功を積み重ねる
- **変革エージェント**: 組織内の推進者を育成

## 想定される学習成果

- 技術変革における人間的側面の重要性を理解
- 抵抗を「問題」ではなく「情報」として捉えるマインドセット
- AMETの立ち上げから撤退までのライフサイクル設計能力
- 変革パターンを状況に応じて適用する判断力
