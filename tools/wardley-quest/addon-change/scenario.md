# 第1章: ゲーム概要

## 1.1 このゲームについて

**Change Leadership Quest** は、Strategic Evolution Questの拡張として、**モダナイゼーションを成功に導く組織変革のリーダーシップを学ぶ**戦略シミュレーションRPGです。

技術的に正しい判断をしても、組織が変化を受け入れなければモダナイゼーションは失敗します。AMET（Architecture Modernization Enabling Team）の考え方を活用し、組織全体の変革を推進します。

### 核心的な問い

> **「技術的に正しい変化を、どうすれば組織全体に浸透させ、持続可能なものにできるのか？」**

### 変革の現実

| よくある失敗 | 変革リーダーシップで防げること |
|---|---|
| 「正しいのに採用されない」 | 変化への抵抗を理解し対処 |
| 「一部だけで終わる」 | 組織全体への展開戦略 |
| 「元に戻ってしまう」 | 持続可能な変化の定着 |
| 「孤立して終わる」 | スポンサーシップと連携 |
| 「燃え尽きる」 | 適切なペースと支援 |

## 1.2 組織変革の本質

### Nick Tuneの洞察

Architecture Modernizationでは、**技術的な変革は常に組織的・文化的な変革を伴う**と強調されています。

| 視点 | 説明 |
|---|---|
| **人が中心** | 変革は技術ではなく人が行う |
| **抵抗は自然** | 変化への抵抗は人間の本能 |
| **信頼が基盤** | 変化には心理的安全性が必要 |
| **持続性が重要** | 一時的な変化ではなく定着 |

## 1.3 ゲームの厳しさについて

このゲームでは以下のことが起こります：

| 現象 | 説明 | 学び |
|---|---|---|
| **静かな抵抗** | 表立って反対しないが協力もしない | 沈黙を見逃さない |
| **燃え尽き** | 変革推進者が疲弊する | 持続可能なペース |
| **揺り戻し** | 一度進んだものが元に戻る | 定着の仕組み |
| **政治的妨害** | 影響力のある人が妨害 | ステークホルダー管理 |
| **スポンサー喪失** | 支援者がいなくなる | 複数の支持者確保 |
| **Success Theater** | 表面的な成功を装う | 本質的な変化を見る |

**これらは現実の変革プロジェクトで直面する課題です。**

## 2.2 判定システム

### 基本判定（2D6）

| 出目 | 結果 | 効果 |
|:---:|---|---|
| 2 | **致命的失敗** | 変革の頓挫。スポンサー喪失の危機。 |
| 3-4 | **失敗** | 抵抗増加。進捗後退。 |
| 5-6 | **部分的失敗** | 限定的な進展。副作用あり。 |
| 7-8 | **部分的成功** | 基本的な進展。追加の努力が必要。 |
| 9-10 | **成功** | 計画通りの進展。 |
| 11 | **大成功** | 予想以上の進展。新たなチャンピオン獲得。 |
| 12 | **完全成功** | 変革の転換点。自発的な拡大。 |

### 修正値

#### リーダーシップ関連

| 状況 | 修正 | 根拠 |
|---|:---:|---|
| 明確なビジョンがある | +2 | 方向性の共有 |
| スポンサーが積極的 | +2 | 後ろ盾の確保 |
| チャンピオンネットワークが充実 | +1 | 推進力の分散 |
| 成功事例がある | +1 | 説得力の向上 |
| ビジョンが曖昧 | -2 | 方向性の混乱 |
| スポンサー不在 | -3 | 後ろ盾の欠如 |
| チャンピオンが孤立 | -1 | 燃え尽きリスク |

#### 組織文化関連

| 状況 | 修正 | 根拠 |
|---|:---:|---|
| 心理的安全性が高い | +2 | 失敗を恐れない |
| 学習文化がある | +1 | 変化への受容性 |
| 過去に成功体験がある | +1 | 変化への自信 |
| 恐怖文化 | -2 | 変化への抵抗 |
| 過去に失敗がある | -1 | 変化への不信 |
| サイロ化している | -1 | 連携の困難 |

#### 抵抗関連

| 状況 | 修正 | 根拠 |
|---|:---:|---|
| 抵抗の理由を理解している | +1 | 適切な対応 |
| 抵抗者を巻き込んでいる | +1 | 味方への転換 |
| 強力な抵抗勢力がいる | -2 | 変革の妨害 |
| 抵抗を無視している | -1 | 問題の放置 |

## 2.3 組織イベント

毎ターン開始時にD6を2回振り、2つのイベントが発生します。

### 組織イベント表

| D6 | イベント | 効果 | 対応のヒント |
|:---:|---|---|---|
| 1 | **新たな抵抗** | 影響力のある人が反対を表明。抵抗レベル+2。 | 対話、理由の理解 |
| 2 | **チャンピオン疲弊** | 推進者が燃え尽きの兆候。サポートが必要。 | 休息、負荷分散 |
| 3 | **成功事例発生** | どこかで良い結果が出た。活用のチャンス。 | 共有、拡大 |
| 4 | **組織変更** | 部門再編や人事異動。関係再構築が必要。 | 新たなステークホルダーへのアプローチ |
| 5 | **予算圧力** | コスト削減要求。変革活動への影響。 | ROIの説明、優先順位 |
| 6 | **外部からの追い風** | 業界動向や競合の動きが変革を後押し。 | 機会の活用 |

### 常時適用パターン

| パターン | 効果 |
|---|---|
| **変化は遅い** | 一夜にして組織は変わらない |
| **抵抗は消えない** | 管理するもの、排除するものではない |
| **疲労は蓄積する** | 持続可能なペースが重要 |
| **成功は最高の説得** | 小さな勝利を積み重ねる |
| **関係が全て** | 信頼なくして変革なし |

# 付録A: クイックリファレンス

## 変化のS字カーブ位置

| 進捗 | 段階 | 特徴 |
|:---:|---|---|
| 0-15% | イノベーター | 少数の先駆者 |
| 15-50% | 初期採用者 | 臨界点への道 |
| 50% | 臨界点 | 自発的拡大開始 |
| 50-85% | 多数派 | 主流化 |
| 85%+ | 遅延者 | 最後の抵抗 |

## 主要修正値

| 条件 | 修正 |
|---|:---:|
| 明確なビジョン | +2 |
| スポンサー積極的 | +2 |
| 心理的安全性高い | +2 |
| 成功事例あり | +1 |
| スポンサー不在 | -3 |
| 恐怖文化 | -2 |
| 強力な抵抗勢力 | -2 |

## 抵抗対応の原則

1. **傾聴** - まず理解する
2. **共感** - 感情を認める
3. **巻き込み** - 敵を味方に
4. **忍耐** - 時間をかける
5. **柔軟性** - 方法を調整
