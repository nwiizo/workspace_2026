# 第1章: ゲーム概要

## 1.1 このゲームについて

**Change Leadership Quest** は、Strategic Evolution Questの拡張として、**モダナイゼーションを成功に導く組織変革のリーダーシップを学ぶ**戦略シミュレーションRPGです。

技術的に正しい判断をしても、組織が変化を受け入れなければモダナイゼーションは失敗します。AMET（Architecture Modernization Enabling Team）—モダナイゼーションを推進し各チームの能力向上を支援する専門チーム—の考え方を活用し、組織全体の変革を推進します。

### 核心的な問い

> **「技術的に正しい変化を、どうすれば組織全体に浸透させ、持続可能なものにできるのか？」**

### 変革の現実

| よくある失敗 | 変革リーダーシップで防げること |
|---|---|
| 「正しいのに採用されない」 | 変化への抵抗を理解し対処 |
| 「一部だけで終わる」 | 組織全体への展開戦略 |
| 「元に戻ってしまう」 | 持続可能な変化の定着 |
| 「孤立して終わる」 | スポンサーシップと連携 |
| 「燃え尽きる」 | 適切なペースと支援 |

### フレームワークの関係

**変革のリーダーシップ（人と組織の変化）**
1. **AMET** → 変革を支援し、組織の能力を高める
2. **Team Topologies** → イネーブリング（スキル移転）、プラットフォーム（基盤）、ストリームアラインド（実践）
3. **持続可能な変化** → 学習文化の醸成、継続的改善、自律的な進化

## 1.2 組織変革の本質

### Nick Tuneの洞察

Architecture Modernizationでは、**技術的な変革は常に組織的・文化的な変革を伴う**と強調されています。

| 視点 | 説明 |
|---|---|
| **人が中心** | 変革は技術ではなく人が行う |
| **抵抗は自然** | 変化への抵抗は人間の本能 |
| **信頼が基盤** | 変化には心理的安全性が必要 |
| **持続性が重要** | 一時的な変化ではなく定着 |

### 変化のS字カーブ

Innovators → Early Adopters → **[The Chasm]** → Early Majority → Late Majority

**注意**: Early Majorityを巻き込むことが臨界点。イノベーターと初期採用者だけでは成功しない。

# 第2章: ゲームルール

## 2.1 セッション構造

**Phase 1: 変革の準備** → 組織評価、スポンサー確保、チャンピオン発掘、ビジョン策定

**Phase 2: 変革の推進（ターン制）** 各ターンの流れ:
1. 組織イベント（D6×2） — 抵抗・支援・予期せぬ出来事
2. 状況分析 — 変革進捗/レジリエンス/チャンピオン/抵抗
3. アクション宣言（最大3つ）
4. 判定（2D6+修正値）
5. 結果適用 — 進捗・抵抗・チャンピオン状態を更新

**Phase 3: 定着と継続** → 定着度評価、持続の仕組み確立、学びの言語化

# 第3章: AMET（Architecture Modernization Enabling Team）

## 3.1 概要

AMETは、**モダナイゼーションを支援し、組織全体の能力を高める**ための専門チームです。

**AMET = イネーブリングチーム + 変革リーダーシップ**
- イネーブリング: スキル移転、ベストプラクティス共有、技術支援
- 変革リーダーシップ（AMET固有）: 組織変革推進、ステークホルダー管理、定着支援

---

## 3.2 AMETの役割

### 主な活動

| 活動 | 説明 | 成果 |
|---|---|---|
| **コーチング** | チームに寄り添って支援 | スキル向上 |
| **ファシリテーション** | ワークショップの運営 | 合意形成 |
| **知識共有** | ベストプラクティスの伝播 | 組織学習 |
| **調整** | 部門間の橋渡し | 連携強化 |
| **ツール提供** | 変革を支えるツールの整備 | 効率化 |
| **変革支援** | 変化への適応を支援 | 抵抗軽減 |

### AMETの原則

1. **「できるようにする」** — 依存を生まず自立を促す
2. **一時的な存在** — 不要になることが成功
3. **引き際を知る** — 適切なタイミングで手を引く
4. **全体最適** — 特定チームではなく組織全体を見る
5. **変化の体現者** — 自ら模範を示す

---

## 3.3 判定への影響

| 状況 | 判定修正 |
|---|:---:|
| AMETが活動中 | +2 |
| AMETとチームの信頼関係がある | +1 |
| AMETが複数チームを支援 | +1 |
| AMETが不在 | -1 |
| AMETが依存を生んでいる | -1 |

# 第4章: 抵抗への対処

## 4.1 概要

抵抗は変革の自然な一部であり、**理解し、対処すべきもの**です。

### 抵抗の種類

| 種類 | 典型的な声 | 対応 |
|---|---|---|
| **技術的** | 「新しい技術を学ぶのは大変」 | トレーニング、段階的導入 |
| **政治的** | 「私の影響力が低下する」 | 新しい役割の提示、巻き込み |
| **文化的** | 「これまでのやり方が否定された」 | 過去への敬意、価値の継承 |
| **心理的** | 「失敗するのが怖い」 | 心理的安全性、小さな成功体験 |

---

## 4.2 抵抗者のタイプ

### 対応マトリクス

| 影響力＼反対 | 弱 | 強 |
|:---:|---|---|
| **高** | 要注意 → 巻き込む | 最優先 → 対話・交渉 |
| **低** | 観察 → モニター | 対応 → 傾聴・説明 |

---

## 4.3 対処のパターン

### 傾聴から始める

| ステップ | 説明 |
|---|---|
| 1. 聴く | 抵抗の理由を理解する |
| 2. 認める | 感情を否定しない |
| 3. 共感 | 相手の立場で考える |
| 4. 対話 | 共通点を見つける |
| 5. 協働 | 一緒に解決策を考える |

### 避けるべきこと

| パターン | 問題 |
|---|---|
| 無視 | 抵抗が増大する |
| 排除 | 敵を作る |
| 強制 | 表面的な従順、内面の抵抗 |
| 論破 | 感情的な対立 |

# 第5章: 学習文化の醸成

## 5.1 概要

学習文化は、**変革を持続可能にする基盤**です。

### 学習する組織の5要素（Peter Senge）

1. **システム思考** — 全体と相互作用を理解
2. **自己マスタリー** — 個人の継続的成長
3. **メンタルモデル** — 前提を問い直す
4. **共有ビジョン** — 組織全体で目指す姿を共有
5. **チーム学習** — 一緒に学び成長する

---

## 5.2 心理的安全性

### Amy Edmondsonの洞察

| 要素 | 説明 |
|---|---|
| **失敗を罰しない** | 失敗は学習の機会 |
| **質問を歓迎** | 「分からない」と言える |
| **意見を求める** | 全員の声を聴く |
| **助けを求められる** | 弱みを見せられる |
| **リスクを取れる** | 新しいことに挑戦できる |

### 判定への影響

| 状況 | 判定修正 |
|---|:---:|
| 心理的安全性が高い | +2 |
| 失敗から学ぶ文化 | +1 |

| 責任追及文化 | -2 |

| スポンサー喪失 | -5 |
| 強制的変革を実施 | -3 |
| 揺り戻しが発生 | -3 |

## 7.3 バッドエンディング

終了条件による敗北時、以下のエンディングが表示されます。

### 「変革の頓挫」エンディング
**条件**: 抵抗レベルが10以上になった
**学び**: 抵抗は敵ではなく理解すべき対象 / 過去の失敗が新たな不信を生む / 変革は「やらせる」ではなく「一緒に作る」

### 「燃え尽きた火」エンディング
**条件**: チャンピオン全員が燃え尽きた
**学び**: チャンピオンは消耗品ではなく支援が必要 / ヒーロー依存の変革は脆い / ネットワークで負荷を分散する

### 「スポンサーの撤退」エンディング
**条件**: スポンサー全員を失った
**学び**: スポンサーシップは一度得たら終わりではない / 経営層の言語(ROI)で継続的に説明 / 複数スポンサーでリスク分散

### 「表面的な成功」エンディング
**条件**: 変革進捗60%以上かつ組織レジリエンス3以下で終了
**学び**: プラクティス導入と文化変革は別物 / 「なぜ」なき「何を」は定着しない / レジリエンスを育てる長期視点が必要

### 「分断された変革」エンディング
**条件**: チャンピオンが3名以上いるが、連携度が低い
**学び**: 変革の方向性を揃えることが重要 / チャンピオン同士の連携の場を作る / 多様性と一貫性のバランス

### 7.4 決められていないバッドエンディング

| パターン | 発生条件（目安） | 結末の方向性 |
|---------|-----------------|-------------|
| 「変革疲れ」 | 3ターン連続で抵抗レベル上昇 | 組織が変革に免疫を獲得 |
| 「成功者の孤立」 | 1チームだけ進捗80%以上、他20%以下 | 先行チームが孤立 |
| 「経営交代の断絶」 | スポンサー交代イベント発生時 | 方針転換で振り出し |
| 「見せかけのアジャイル」 | 形式だけ導入、心理的安全性なし | 表面的導入が嘘に |

GMはプレイ状況に応じてカスタムバッドエンディングを生成できます。

## 7.5 グッドエンディング

### 「自走する変革」エンディング
**条件**: 変革進捗90%以上、チャンピオンネットワーク5名以上
**学び**: ヒーロー依存ではなくネットワークを育てる / 「一緒にやる」を貫く / 自分不在でも回る仕組みを作る

### 「抵抗が協力に変わった日」エンディング
**条件**: 抵抗レベル2以下、組織レジリエンス8以上
**学び**: 抵抗を「敵」ではなく「声」として聞く / 経験者の知恵を設計に活かす / 「説得」ではなく「共創」

### 「学習する組織」エンディング
**条件**: 全ボーナス条件達成
**学び**: 変革を「イベント」ではなく「文化」にする / 心理的安全性と失敗許容の環境 / 長期視点で組織の学習能力を高める

# 第10章: RPG強化システム

このゲームでは、学習体験を強化するための要素を導入しています。これらの要素は**オプション**であり、基本ルールのみでもプレイ可能です。

## 10.1 プレイヤースペシャリティ

プレイヤーは「変革リーダー」として、以下の4つのスペシャリティから1つを選択できます。

### スペシャリティ一覧

| スペシャリティ | 特徴 | 判定ボーナス | 特殊能力（1ゲーム1回） |
|--------|------|:---:|---|
| **変革コーチ** | 個人とチームの変化支援に優れる | 抵抗対応+1 | 「深い傾聴」: 抵抗者との対話を自動成功、関係値+2 |
| **組織開発スペシャリスト** | 組織構造とプロセス変革に強い | 組織変革+1 | 「構造の再設計」: 組織変更の判定を自動成功 |
| **チェンジコミュニケーター** | ビジョン共有と説得力に長ける | コミュニケーション+1 | 「心に響くメッセージ」: ビジョン共有で変革進捗+10% |
| **AMETリーダー** | イネーブリングと能力構築が得意 | イネーブリング+1 | 「チームの覚醒」: AMET活動の効果を2倍 |

迷ったら**変革コーチ**がおすすめ。

## 10.2 NPCシステム

以下は代表的なNPC。GMはシナリオに応じて追加・変更可能。

| NPC名 | 役割 | 特徴 | 関係値影響（良好/悪化） |
|-------|------|------|------------------------|
| **村上社長** | CEO（スポンサー） | ビジョナリー、変革を強く支持 | スポンサーシップ+2 / 変革優先度低下 |
| **前田専務** | COO（スポンサー） | 実務重視、成果を求める | リソース確保+1 / 予算削減 |
| **中山マネージャー** | 中間管理職 | 変革に懐疑的、部下を守りたい | チャンピオン化可能 / 静かな抵抗 |
| **遠藤エンジニア** | シニアエンジニア | 技術的に賛成、速度に不安 | 技術支援+2 / 消極的協力 |
| **大野オペレーター** | 現場スタッフ | 現状慣れ、変化に不安 | 草の根支持+1 / 不満拡散 |

### 関係値システム

NPCとの関係値は **-3〜+3** の範囲で変動します。

| 関係値 | 状態 | 効果 |
|:---:|---|---|
| +3 | 強い支持 | チャンピオンとして活動、他者を巻き込む |
| +1〜+2 | 協力的 | 変革に参加、必要な協力を提供 |
| 0 | 中立 | 様子見、指示があれば従う |
| -1〜-2 | 消極的 | 静かな抵抗、最小限の協力 |
| -3 | 敵対 | 積極的な抵抗、変革を妨害 |

### 関係値の変動

| 行動 | 変動 |
|------|:---:|
| NPCの懸念に傾聴し対処 | +1 |
| NPCを変革に巻き込む | +1 |
| NPCの成功を認める | +1 |
| NPCの意見を無視して進める | -1 |
| NPCに過度な変化を強制 | -2 |
| NPCの失敗を公に批判 | -2 |
