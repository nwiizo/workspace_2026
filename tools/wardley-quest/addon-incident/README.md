# Incident Management Quest

[Strategic Evolution Quest](../) のアドオンシナリオ

本番インシデントへの対応・復旧・振り返りを学ぶRPG。「本番が落ちた！」という緊迫した状況で、インシデントコマンダーとして適切な判断を下し、ブレームレスな文化を築きます。

## 前提

**単体でもプレイ可能です。** [Strategic Evolution Quest](../) や [Platform Quest](../addon-platform/) をプレイ済みだとより深く理解できます。

## 学べる概念

### インシデント対応の基本

- **重大度（Severity）レベル**: SEV1〜SEV4の分類と対応優先度
- **インシデントコマンダー**: 混乱の中で冷静に指揮を執る役割
- **コミュニケーション**: ステークホルダーへの適切な情報伝達
- **エスカレーション**: いつ、誰に、どうエスカレートするか

### SRE/DevOpsプラクティス

- **SLO（Service Level Objectives）**: サービスレベル目標とエラーバジェット
- **SLI（Service Level Indicators）**: 信頼性を測る指標
- **オンコール**: 持続可能なオンコール体制の設計
- **ランブック**: インシデント対応の標準手順書

### ブレームレス文化

- **ポストモーテム**: 責任追及ではなく学習のための振り返り
- **心理的安全性**: 失敗を報告できる環境づくり
- **システム思考**: 個人の失敗ではなくシステムの改善に注目
- **貢献因子分析**: 「誰が悪い」ではなく「何が寄与したか」

### カスケード障害と複雑系

- **連鎖的障害**: 一つの障害が他のシステムに波及するパターン
- **サーキットブレーカー**: 障害の連鎖を止めるパターン
- **グレースフルデグラデーション**: 部分的に機能を落としてサービスを継続
- **カオスエンジニアリング**: 本番で障害に強いシステムを構築する手法

## 想定される学習成果

- インシデント対応の標準プロセスを理解し実践できる
- SLO/SLIに基づいた信頼性の考え方を身につける
- ブレームレスポストモーテムを効果的に実施できる
- 障害に強いシステムを設計する視点を獲得する

## 遊び方

生成AIに [scenario.md](./scenario.md) を読み込ませて、以下を伝える：

```
Incident Management Questをプレイしたいです。
シナリオ: 0（学習モード）
```

## シナリオ

| # | 名前 | 難易度 | 学習焦点 |
|---|---|---|---|
| 0 | 学習モード | チュートリアル | インシデント対応の基本とコミュニケーション |
| 1 | 初の大規模障害 | ★★☆ | 単一システム障害の対応と復旧 |
| 2 | カスケード障害 | ★★★ | マルチシステム障害と協調対応 |
| 3 | ポストモーテム改革 | ★★★★ | インシデントからの組織学習と文化変革 |
| 4 | カスタム | 可変 | あなた自身の組織のインシデント |
