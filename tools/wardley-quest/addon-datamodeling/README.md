# Data Modeling Quest

[Strategic Evolution Quest](../) のアドオンシナリオ

DDDに基づくデータ設計RPG。境界づけられたコンテキストをデータモデルとして実装する方法を学びます。

## 前提

[Strategic Evolution Quest](../) をプレイ済み、または並行してプレイすることを推奨。

## 参考書籍

- Architecture Modernization (Nick Tune)
- ソフトウェア設計の結合バランス (Vlad Khononov) - 品質指標として活用

## 遊び方

生成AIに [scenario.md](./scenario.md) を読み込ませて、以下を伝える：

```
Data Modeling Questをプレイしたいです。
シナリオ: 0（学習モード）
```
