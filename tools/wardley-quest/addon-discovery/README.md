# Discovery Workshop Quest

[Strategic Evolution Quest](../) のアドオンシナリオ

ステークホルダー理解とドメイン発見のためのワークショップ手法を学ぶRPG。リスニングツアー、インパクトマッピング、リスクストーミングなどの手法を実践します。

## 前提

**単体でもプレイ可能です。** [Strategic Evolution Quest](../) をプレイ済みだとより深く理解できます。

## 学べる概念

### リスニングツアー

Nick Tuneが強調する、モダナイゼーション前の重要な発見フェーズ：

- **ステークホルダーインタビュー**: 各部門の課題、期待、懸念を収集
- **暗黙知の発見**: ドキュメントに書かれていない重要な情報
- **政治的地形の把握**: 組織内のパワーダイナミクスと意思決定構造
- **現状の痛みの可視化**: 日常的に直面している問題の優先順位付け

### インパクトマッピング

Gojko Adzicが考案した、ビジネスゴールから逆算する発見手法：

- **Why（なぜ）**: ビジネスゴールの明確化
- **Who（誰が）**: 影響を与えるアクターの特定
- **How（どのように）**: 行動変容の定義
- **What（何を）**: 必要な機能・成果物の導出

### ユーザーストーリーマッピング

Jeff Pattonの手法による、ユーザー体験中心の発見：

- **バックボーンの特定**: ユーザーの主要なアクティビティ
- **ウォーキングスケルトン**: 最小限のEnd-to-Endフロー
- **リリース計画**: MVPから段階的な拡張

### リスクストーミング

アーキテクチャリスクの協調的な発見手法：

- **リスクの可視化**: 技術・組織・ビジネスリスクのマッピング
- **優先順位付け**: 影響度と発生確率による評価
- **緩和策の検討**: リスク対応戦略の立案

### 言語化の力

曖昧さから脱する表現力の養成：

> 「なんか」という曖昧さから脱する言語化の力

- **曖昧さの言語化**: 「なんとなく違和感がある」を具体的な課題に変換
- **暗黙知の形式知化**: 言葉にできなかった知識を共有可能にする
- **システム思考を言葉にする**: 複雑な相互作用を説明する能力
- **AI時代のコミュニケーション**: 生成AIに適切に指示を出す表現力

### 読解力と文章理解

発見フェーズで重要な情報処理能力：

- **読解力の分解**: 字面の理解、文脈の把握、意図の推測
- **中身のある話の作り方**: 発見した内容を価値ある情報に構造化
- **ステークホルダーの言葉を正確に捉える**: 誤解を防ぐ確認技術

## 想定される学習成果

- ステークホルダーから効果的に情報を引き出すインタビュー技術
- 暗黙知を可視化し、共有可能な知識に変換する能力
- ビジネスゴールと技術的な施策を結びつける思考
- ワークショップを設計・ファシリテートする実践力
