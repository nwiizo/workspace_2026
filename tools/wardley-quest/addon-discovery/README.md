# Discovery Workshop Quest

[Strategic Evolution Quest](../) のアドオンシナリオ

ステークホルダー理解とドメイン発見のためのワークショップ手法を学ぶRPG。リスニングツアー、インパクトマッピング、リスクストーミングなどの手法を実践します。

## 前提

[Strategic Evolution Quest](../) をプレイ済み、または並行してプレイすることを推奨。

## 参考書籍

- Architecture Modernization (Nick Tune) - Ch.4 Listening and Mapping Tours
- Impact Mapping (Gojko Adzic)
- User Story Mapping (Jeff Patton)

## 遊び方

生成AIに [scenario.md](./scenario.md) を読み込ませて、以下を伝える：

```
Discovery Workshop Questをプレイしたいです。
シナリオ: 0（学習モード）
```
