# Addon: Federation

フェデレーテッドコントロールプレーン・マルチリージョン展開のアドオン。

> 「一つのコントロールプレーンに、世界の全責任を背負わせるな」

## 学べること

- フェデレーションのトポロジー（ハブ&スポーク / メッシュ / 階層）
- リージョン跨ぎの整合性と可用性のトレードオフ
- グローバル CP と ローカル CP の責任分担
- 災害時のリージョン切り替え

## メインとの繋がり

- メインシナリオ 3 T1-T4 通読
- addon-control-plane の上位
- BAD-T3「コントロールプレーン融解」のスケール版回避
