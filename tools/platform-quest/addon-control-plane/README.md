# Addon: Control Plane

宣言的 API・リコンサイル・コントロールプレーン基礎を扱うアドオン。

> 「コントロールプレーンとは、組織の意図と現実のクラウドを繋ぐ仲介者である。
>  それが壊れた時、組織は『何を望んでいたか』を思い出せなくなる」

## 学べること

- 宣言的API vs 命令的スクリプトの設計選択
- リコンサイルループの設計（drift detection / self-healing）
- カスタムリソースとサードパーティ連携
- コントロールプレーン自体の SRE

## メインとの繋がり

- メインシナリオ 1 T3-T4 で「自作 or OSS」の選択に直結
- BAD-T3「コントロールプレーン融解」への警戒
- addon-federation の前提
