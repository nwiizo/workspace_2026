# Addon: Observability

シグナル駆動フィードバックループと進化的オブザーバビリティを扱うアドオン。

> 「観測できないシステムは、運用できないシステムである。
>  そして、観測しているのに行動が変わらないなら、それは観測していないのと同じだ」

## 学べること

- メトリクス・ログ・トレースの統合戦略
- SLI/SLO/エラーバジェットの実運用
- 「シグナル → 意思決定」のフィードバックループ設計
- コストと信号品質のトレードオフ

## メインとの繋がり

- メインシナリオ全体で「データに基づく行動 +1」修正の源泉
- BAD-T3「コントロールプレーン融解」防止
- GOOD-F1「投資 ROI 証明」の土台
