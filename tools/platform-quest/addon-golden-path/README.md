> 「ゴールデンパスは『正しい道』ではない。

- 「逸脱の自由」と「逸脱のコスト」の設計
- テンプレート vs ジェネレーター vs スキャフォールド
- 初期摩擦の最小化（README ゼロのデプロイ）
