# Addon: Product Thinking

プラットフォームを**プロダクトとして扱う**思考を体験するアドオン。

> 「ユーザーがいないプロダクトはプロダクトではない。
>  そして、社内向けプラットフォームには、最も愛されにくい種類のユーザーがいる。
>  彼らは『使うことを強制された』とき、無言で去る」

## このアドオンで学べること

- ユーザーリサーチ（社内ユーザーは取材が難しい）の組み立て方
- 機能ロードマップを「機能の列挙」ではなく「アウトカムの列挙」に変える方法
- ペルソナ・JTBD・PMF（プロダクトマーケットフィット）を**社内向け**に翻訳する
- 「使うと宣言されたが、使われていないプラットフォーム」の検知

## メインとの繋がり

- メインシナリオ 1（グリーンフィールド）T1-T2 直後に推奨
- アスカ（PdM）が活躍する
- メインの BAD-O3「サイロ強化」と GOOD-T1「ゴールデンパスの定着」の分岐に直結
