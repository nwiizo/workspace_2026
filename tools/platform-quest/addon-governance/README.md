# Addon: Governance

ガバナンス・コンプライアンス・信頼を**速度を殺さずに**両立するアドオン。

> 「セキュリティは速度の対義語ではない。**未制御**が速度の対義語だ」

## 学べること

- Policy as Code（OPA, Rego, Conftest）の導入と運用
- 監査要求とゴールデンパスの融合
- 「No と言わない」セキュリティチームの組み立て
- SOC2 / ISMS 等の認証対応

- ハルカが活躍
- メインシナリオ 1 T11-T12（SOC2 直前）の必読アドオン
- BAD-O2「プラットフォーム警察化」防止
