# Addon: AI-Augmented Platform

AI 拡張プラットフォーム・自己進化・推論コストを扱うアドオン。

> 「AI はプラットフォームの上に乗るアプリではない。
>  プラットフォーム自体の**設計者と運用者の片割れ**になる」

## 学べること

- LLM/AI を組み込んだプラットフォーム機能の設計
- AI による自己診断・自己修復
- 推論コストと精度のトレードオフ
- ハルシネーション・暴走の安全装置

## メインとの繋がり

- メインシナリオ 3 の終盤、または未来シナリオとして
- 上位成熟度（Lv4-5）への入口
- GOOD-T2「自己進化プラットフォーム」の現実版
