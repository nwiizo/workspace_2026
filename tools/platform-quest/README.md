# Platform Quest

開発者に愛され、組織を倍力する**内部プラットフォーム**を構築・運用・進化させる戦略シミュレーションRPG。

> 「プラットフォームは静的なインフラではない。プロダクトであり、進化する生き物である。」

## 何を学べるか

- プラットフォームエンジニアリングの中核原則（プロダクト思考、認知負荷削減、セルフサービス、ケイパビリティモデル）
- 内部プラットフォームを **誰のための、何の問題を解く** プロダクトとして設計する視点
- ガバナンス・オブザーバビリティ・コントロールプレーンといった土台を「速度を殺さずに」積む順序
- マルチテナント、フェデレーション、コスト、廃止、AI拡張といったスケール期の判断
- 障害・経営層・採用拡大・コスト急騰といった外圧の中で、開発者信頼を失わない立ち回り

## 5分で始める

1. [scenario.md](./scenario.md) を生成AI（Claude / ChatGPT 等）にコピペする
2. 「シナリオ0を**短縮版**で」と伝える
3. 2〜3ターンで基本ループを体験（約15分）

短縮版では判定+2のボーナス付きで、リソース管理と気候イベントの基本を素早く学べます。

## プレイ方法

生成AIに [scenario.md](./scenario.md) を読み込ませて以下を伝えるだけ:

```
Platform Questをプレイしたいです。
シナリオ: 0（学習モード）
難易度: Normal
```

AIが状況描写・選択肢提示・判定・気候イベントを順にこなしてくれます。

## プレイ支援機能

### 出力モード

LLMのコンテキストを節約するため、3つの出力モードを用意。

| モード | 説明 | 使用場面 |
|---|---|---|
| 通常モード | 標準的な出力量 | 通常プレイ |
| コンパクトモード | 最小限の出力で進行 | 長時間プレイ、コンテキスト節約 |
| 詳細モード | 豊富な描写と演出 | 世界観を味わいたい時 |

切替コマンド例:

```
コンパクトモードに切り替えてください
詳細モードに切り替えてください
通常モードに戻してください
状態確認
サマリーをください
```

コンパクトモード出力例:

```
【T4】状況: 主要利用チームが「内製ツールに戻す」と通告
選択肢: A)プロダクトインタビュー B)ゴールデンパス改修 C)経営層エスカレ
状態: 予算[60] 信頼[+1] 認知負荷[+3] 成熟度[35] 負債[中]
```

### 難易度

| 難易度 | 判定修正 | 気候イベントの厳しさ | 想定プレイ時間 |
|---|---|---|---|
| Easy | +1 | 1段階弱め | 30〜45分 |
| Normal | ±0 | 通常 | 45〜60分 |
| Hard | -1 | 1段階強め | 60〜90分 |
| Expert | -2 | 2段階強め + 二重イベント | 90分〜 |
