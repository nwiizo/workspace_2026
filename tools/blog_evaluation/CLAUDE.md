# CLAUDE.md - Blog Evaluation

## 概要

ブログ記事評価プロンプト v2.2

## コマンド

```
/evaluate [ファイルパス]
```

## 評価観点（7つ）

| 観点 | 内容 |
|------|------|
| 防御力 | 批判に耐えうるか |
| 思考整理力 | 論理的に構造化されているか |
| 実践応用性 | 読者が行動に移せるか |
| 構成と読みやすさ | 読者の理解を促進するか |
| コミュニケーション力 | 人間味があるか |
| 炎上リスク | 社会的配慮があるか（高いほど安全） |
| 人間らしさ | AIっぽくないか |

## スコア基準

- **5.0**: 例外的（全体の5%未満）
- **4.0**: 商業メディアレベル
- **3.0**: 標準的
- **2.0以下**: 改善が必要

## ファイル

- `evaluation-prompt.md` - 詳細な評価基準
