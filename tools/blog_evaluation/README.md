# ブログ記事評価プロンプト

Claude Codeが記事を評価するためのプロンプト集。

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `evaluation-prompt.md` | 総合評価プロンプト v2.3（7観点） |

## 評価観点（7つ）

1. **防御力** - 批判に耐えうるか
2. **思考整理力** - 論理的に構造化されているか
3. **実践応用性** - 読者が行動に移せるか
4. **構成と読みやすさ** - 読者の理解を促進するか
5. **コミュニケーション力** - 人間味があるか
6. **炎上リスク** - 社会的配慮があるか（高いほど安全）
7. **人間らしさ** - AIっぽくないか

## 使い方

### 総合評価

```
tools/blog_evaluation/evaluation-prompt.md を読んで、この記事を評価して
```

### 特定観点のみ

```
tools/blog_evaluation/evaluation-prompt.md の「防御力」の基準で評価して
```

```
tools/blog_evaluation/evaluation-prompt.md の「炎上リスク」をチェックして
```

## .claude/commands/ との違い

| 種類 | 用途 | 実行方法 |
|------|------|----------|
| `.claude/commands/` | フォーマット済みレビュー | `/full-review blog.md` |
| `tools/blog_evaluation/` | 柔軟な評価プロンプト | AIへの指示で参照 |

- **commands**: 決まった形式のレポートを出力
- **blog_evaluation**: 対話的に評価・改善を進める

## スコア基準

- **5.0**: 例外的に優れた記事（全体の5%未満）
- **4.0-4.9**: 商業メディア掲載レベル
- **3.0-3.9**: 標準的な技術ブログ
- **2.0-2.9**: 改善が必要
- **1.9以下**: 大幅な改善が必要
