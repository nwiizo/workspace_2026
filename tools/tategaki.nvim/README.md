# tategaki.nvim

Markdown を Neovim 内でページ送りしながら縦書きで読む、小さな Lua プラグインです。本文は上から下、右の列から左の列へ進みます。コードフェンス（Mermaid や ASCII 図を含む）、インデントしたコード、表、画像参照、SVG ソースは文書中の位置で横書きのページになります。

## 必要なもの

- Neovim 0.10 以降
- 横幅 2 セルの日本語文字を表示できるターミナルとフォント

外部プラグインへの依存はありません。

## 導入

lazy.nvim でこのリポジトリから使う場合:

```lua
{
  dir = "/path/to/workspace_2026/tools/tategaki.nvim",
  name = "tategaki.nvim",
  cmd = "Tategaki",
}
```

Markdown バッファで `:Tategaki` を実行します。読み取り用の新しいタブが開き、元のバッファは変更されません。

| キー | 動作 |
| --- | --- |
| `n` | 次のページ |
| `p` | 前のページ |
| `r` | 元のバッファから読み直す |
| `q` | 閉じて元のタブに戻る |

横書きページの長い行は Neovim の `zl` / `zh` で横スクロールできます。画面の高さと幅が変わると、表示は現在のページ番号を基準に組み直されます。

## 表示範囲

見出し、箇条書き、強調、インラインコード、リンク文字列を読みやすい文字列に簡略化します。縦書きの句読点と括弧は縦向きの文字へ置き換えます。複雑な Markdown の完全なレンダリング、画像ファイルの描画、Mermaid の図形化には対応していません。画像は代替テキストと参照先を横書きで表示し、Mermaid はコードを横書きで表示します。ラテン文字は一文字ずつ縦に並びます。
