# CLAUDE.md - Memory Optimizer

## 概要

CLAUDE.md を最小限のスタートアップコンテキストにリファクタリングするツール。

## コマンド

```
/optimize [ファイルパス]
```

## 使用タイミング

- CLAUDE.md が50行を超えたとき
- スタートアップが遅く感じるとき
- メモリ構造を再編成したいとき

## ファイル

| ファイル | 内容 |
|----------|------|
| `optimization-guide.md` | 詳細な最適化ガイド |
| `templates.md` | ファイルテンプレート集 |
