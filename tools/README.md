# tools/ 🔧

Where ideas go to become either useful software or abandoned side projects.

## What's Here

- CLI tools that solve problems I have (and maybe you have too)
- Verification code for blog articles
- Experiments that got out of hand (in a good way)
- Things I built at 2 AM and somehow still work

## Philosophy

Ship it. If it breaks, fix it. If it's ugly, refactor it. If no one uses it, at least you learned something.

## Naming Convention

```
2026-topic-name/    # Blog verification code
tool-name/          # Standalone tools
experiment-name/    # "Let's see what happens"
```

## .gitignore

This directory has its own `.gitignore` because `node_modules/` and `target/` don't need to be committed. Ever. 🙅
