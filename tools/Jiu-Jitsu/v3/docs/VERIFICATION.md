# v3.0.0 の確認結果

2026年9月8日の人形更新では、プロット→画像生成→構造設計→モデリング→最適化を実施。[制作記録と実測値](model-production/README.md)を追加した。最終確認は型検査、16ファイル・545テスト、ビルドが成功。3面・骨格・寝技、ビルド版の参照画像、編集したルートの再生、対戦の応答を確認した。以下は9月7日時点の確認記録。

2026年9月7日、ローカルの開発版とビルド版で確認。

- `npm run check`：TypeScript strictの検査を通過。
- `npm test`：15ファイル、538テスト通過（最終実行15:43 JST）。
- `npm run build`：成功。JavaScriptは約717 kB、gzip約193 kB。Viteの500 kB超のチャンク警告あり。
- `git diff --check`：問題なし。

追加動作のテストでは、可変長区間の再生・再開と干渉区間の飛び越し、メッシュ更新、手の厚みを考慮した床の判定、対戦の行動とサイドからの一本、ハーフガード・タートルの手順について変更前の失敗を確認してから実装した。既存の全課題・全ポーズ検査も継続した。

複数ルートの保存・独立した編集・削除・20件の上限・JSONの往復にもテストを追加し、機能がない状態で失敗することを確認してから実装した。不正な単体ルートや一覧の読み書きで、元の保存文字列が変わらないことを検証した。

ブラウザでは以下を確認した。

| 対象 | 確認結果 |
