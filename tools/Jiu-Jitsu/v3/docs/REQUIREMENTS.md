# v3.0.0 の要件と対応

身体を動かして作用を理解し、二人の位置関係を練習し、自作ルートや相手の反応を見直せるブラウザツール。2026年9月7日の依頼までを対象にする。従来の技名クイズは入口にしない。

| 依頼 | 利用者が確認できる動作 | 主な検証 |
|---|---|---|
| 骨格・肉体と動作の作用を理解したい | 道場の3実験で、点・スライダーを動かすとテコ、支持範囲、脚の位置が変わる。骨格／筋肉と前後を比較できる | `mechanics.test.ts`、ブラウザの操作 |
| 人形と接地を見直し、骨が不自然に動く問題を直したい | 固定長の骨と曲げ方向から肘・膝を求める。届かない目標で骨を伸ばさず、床・体幹への侵入を指摘。横・上・斜めで確認できる | `practicePose.test.ts`、`rollPose.test.ts`、`route.test.ts`、3D監査画面 |
| 人形を動かしてルートを作り、無理な動きを指摘してほしい | 二人の手足・腰を直接操作し、最大40姿勢を登録。登録時と途中の再生を検査し、問題位置で停止して理由を表示 | `route.test.ts`、`routePlayback.test.ts`、実際のドラッグ・再生 |
| 作成と確認は別ページ、再利用と自動再生も必要 | `#route` / `#route-watch`、自動保存、最大20件の保存一覧、JSON書き出し・読み込み、速度・途中移動・停止・再開・繰り返し | `routeStorage.test.ts`、ブラウザのファイル往復・再読込・取消 |
| 様々な状況、ポジションから極めまでの例題がほしい | 14課題、11ルート、4つの連続例題。サイドから腕十字、ガードから三角、トップ交代と維持を観察できる | `practice.test.ts`、`practicePose.test.ts`、全登録ルートの再生 |
| 英語資料と最新の動向を調べて練習を登録してほしい | ハーフガード上下、タートル攻守、オープンガードの5課題に英語資料・箇所・確認日。2026年の大会報告を参考にした3ルートと出典 | [READMEの参考資料](../README.md#参考資料と調査日)、課題内の出典表示 |
| 応用ロールを対戦らしくし、選択肢と変遷を増やしてほしい | 青と赤が一手ずつ応答。12種類の行動から上下・位置・余力に合うものを選び、返しや位置の前進、一本を試す。履歴を選んで再生できる | `duel.test.ts` の64対戦、ブラウザでトップ交代・履歴・番号操作 |
| 技術を再選定してv3.0.0として起動したい | 独立した `v3/`、バージョン表示、標準ブラウザの操作と保存。指定されたリポジトリを確認し、依存追加なしで描画と再生を修正 | [技術選定](TECH_SELECTION.md)、型検査・ビルド・起動確認 |

## 成立範囲

指摘は模式図の幾何学的な検査で、人体の可動域・柔軟性・筋力・肩や股関節の回旋・組織変形を網羅しない。全表面の接触や連続衝突検出も扱わない。実技の可否・安全の保証には使わない。

短いルートの姿勢間は補間する。返し・パス・脚の組み替えなど未実装の移行は、飛ばした動きを説明して局面を切り替える。対戦も状態に応じた局面表示で、自由な全身物理シミュレーションではない。

英語資料は公開説明の範囲で確認し、教材動画を再現しない。大会記事は練習の着眼点として使用し、選手の具体的な動作の再現や流行の頻度を主張しない。ADCC 2026は確認日の時点で開催前。継続的な自動巡回は実装範囲に含めない。

データは利用中のブラウザへ保存する。アカウント・オンライン対戦・クラウド同期は設けない。対戦の履歴は現在の対戦だけに保持し、稽古記録は身体の発見とポジション練習の確認・復習を表示する。

再現方法と実際に通した項目は [確認結果](VERIFICATION.md)を参照。
