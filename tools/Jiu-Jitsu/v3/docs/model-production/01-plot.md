# 柔術用人形の制作プロット

2026年9月8日。制作順は、プロット → 画像生成による3面図 → モデル構造設計 → モデリング → 最適化。

## 人形が担うこと

利用者は二人を回して観察し、手足や腰を動かしてルートを作る。ガード、横向き、うつ伏せ、マウントでも、頭の向き、胸と背中、肘と膝の折れる側、床に触れる場所が読める人形にする。青と赤は同じ体格を使う。

中立的な成人の練習用人形。大きな筋肉の塊を誇張せず、頭蓋・顎・首、胸郭から腰への絞り、骨盤、上腕・前腕、太腿・すねを立体としてつなぐ。身体の形が見える無地の密着した練習着を想定し、靴・帯・髪・装備は付けない。骨格表示は別の観察層として保持する。

## 見た目で伝える優先順位

1. 正面：肩から腰への輪郭、左右の腕と脚の分離、頭の向き。
2. 側面：後頭部、顎から首、胸と背中の厚み、足の長さ。胸だけを前に盛らない。
3. 背面：肩甲骨周辺の広がり、背中から腰への絞り、臀部と太腿のつながり。
4. 寝技：肘と膝を曲げても節が離れず、膝・手・足の床への接触が見える。

## 3面図の指定

正面・右側面・背面を同じ縮尺で横並びにする。遠近のない投影、同じ中立姿勢、頭頂・肩・腰・膝・足裏の高さを合わせる。腕は身体から少し離したAポーズ。側面は向かって右を向き、腕の重なりを避けるために姿勢を変えない。

目安は身長約1.68m、約7頭身、肩の関節間0.40m、上腕0.28m、前腕0.26m、太腿0.41m、すね0.40m。画像上の寸法から人体の限界を決めない。画像は形の参考とし、実装寸法と動作の範囲は設計文書へ記載する。

## 使用中の場面での確認

- 中立姿勢を正面・右側面・背面と斜め後ろから見る。
- マウント、ハーフガード、タートル、腕十字を同じ照明で見る。
- 身体／骨格／透過を切り替え、保存済みルートを再生する。
- 最適化前後の三角形数、geometry数、描画呼び出し数を同条件で比較する。速度の測定なしに高速化率を主張しない。

既存の固定長IK、ルート形式、青赤の役割、接地と干渉の検査を保つ。造形と形状の軽量化を今回の変更範囲とする。
