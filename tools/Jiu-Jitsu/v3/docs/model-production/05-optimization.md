# 最適化と検証

造形を3面で確認してから、次の変更を行った。

- 胴体・頭・肋骨など、このリグで一緒に動く部品を骨盤基準の座標へ変換し、材質ごとに結合する。固定部分の姿勢更新は3メッシュを動かす処理になった。
- 左右の手足と関節で同じ形状を共有する。各人形が自分の形状を管理し、破棄時に一度ずつ解放する。
- 頭と胴体の周方向を32→24、四肢を32→16、骨格の小さい球を20×16→12×8に調整した。骨格の管は長さ方向を18→12にした。
- 動く手足は既存メッシュの位置・回転・大きさを更新する。曲面の再生成と固定部分の結合は生成時に行う。

`/_model-audit.html`、1440×1000、基準立位、同じ直交投影と照明。三角形数は身体・骨格の全メッシュの合計、geometry数は実際に参照される形状の種類数。描画呼び出しは1ビュー・人形1体分で、マット・影・接点の描画を含まない。

| geometry数 | 74 | 74 | 11 |

造形後に比べ、全形状の三角形数は約54%、骨格表示の描画呼び出しは約45%減った。処理時間やFPSの向上率は測定していない。

## 検証

2026年9月8日、`npm run check`、`npm test`（16ファイル・545テスト、16:59 JST）、`npm run build`を通過。

新しいテストは、立位の足の前方向と足裏、頭・胴体の閉じた面と向き、三角形・描画・共有形状の予算、共有形状の解放、傾けた股関節だけが床へ入る場合の指摘を確認する。足の逆向き、最適化の予算超過、股関節の検査漏れについて、修正前の失敗を確認した。

既存の保存・再生・対戦のテストも通過し、メッシュ更新後と新しく生成した人形の外形が一致する検証を維持した。横向きで生成したモデルを立位・タートル・マウント・腕十字へ更新しても、固定部分がずれないことを追加で検証した。
