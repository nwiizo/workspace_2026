# 人形の制作工程 — 2026年9月8日

プロット作成 → 3面図の画像生成 → モデル構造設計 → モデリング → 最適化の順で、v3の練習・ルート・対戦に使う人形を更新した。

| 工程 | 成果物 |
|---|---|
| 1. プロット | [用途・見た目・動作中の確認項目](01-plot.md) |
| 2. 3面図の画像生成 | [正面・右側面・背面のPNG](assets/reference-three-view.png)、[実行したプロンプト全文](02-three-view-prompt.txt)。組み込みの画像生成ツールを使用 |
| 3. モデル構造設計 | [部品・接続・寸法と動作の範囲](03-structure.md) |
| 4. モデリング | [造形の変更と比較](04-modeling.md)。形状は `src/render/mannequinShape.ts`、関節への配置は `mannequin.ts` |
| 5. 最適化 | [実測値と検証](05-optimization.md)。固定部品の結合・形状共有・分割数の調整 |

アプリの「心得」から「正面・側面・背面と骨格を見る」を開ける。直接開く場合は `http://127.0.0.1:5174/_model-audit.html`。ビルドにも同じ確認画面と生成した3面図を含めている。

生成図を見て形状の断面を設計した手続き的なモデル。実装は模式的な顔と手掌、固定長の関節を持つ練習用人形で、画像から3D形状を自動復元したものではない。胴体は剛体、関節の外形は部品の重なりで接続する。既存ルートの形式と関節長は維持している。

制作方法の参考は、前回確認した [modeling-playgroundのモデリング見直しガイド](https://github.com/mizchi/modeling-playground/blob/e4c69b8e11c1bea3c3f7a4e5b1cc04839f5fe2eb/docs/modeling-retake-guide.md)。側面の厚み、背面の量感、形の確認後の最適化、同じ条件での比較を適用した。
