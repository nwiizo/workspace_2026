# 柔術ディフェンス道場 — Jiu-Jitsu Defense Dojo

赤と青の 3D 人体が組み合う、ブラウザ製の柔術教育ゲームです。
一本の**連続したロール（スパーリング）**として進行し、各局面で「正しい一手」を選びます。
正解すると次の局面へ自動で流れて動き続け、間違えるとサブミッションが完成して
**なぜ失敗したか** と **柔術の原則** が解説されます。
正解後の次局面は完全固定ではなく、各選択肢に定義された `reaction`（相手の反応）と
`next` 候補からロールのフォーカスに合うものを選び、直前の結果と矛盾しにくい流れへ寄せます。
`next` は重み付きにできるため、自然な展開は出やすく、完全固定にはなりません。
次局面を差し替えるときは、過去に解いた局面と今後の予定スロットを避け、同じ scenario がロール内で重なりにくいようにしています。
不正解でも `consequence`（相手の追撃）から不利な次局面へ繋がるため、ミスがその場限りで終わりません。
さらに各 scenario は複数の `opponentActions`（相手の初動）を持ちます。現在は 25 件の初動があり、7 局面は 3 件以上の初動を持ちます。同じ局面でも、相手が首を狙うのか、腰のフックで追うのか、姿勢を折るのか、重ねて潰すのかが変わり、判断フェーズの3Dポーズ、読む線、pressure 表示、回答後の「初動の読み」も変化します。さらに一部の選択肢は `requiresAction` / `forbiddenAction` を持ち、絞め手が入ったら首防御、腰フックで追われたらフックを外して肩を床へ戻す、シートベルトで固定されたら肩と腰の線をずらす、腕を隔離されたらアッパ、腰を伸ばされたら膝肘、攻め側で橋を作られたら先にベース回復、バック攻撃中に腰を抜かれたらマウントへ変換、相手が背を向けたらバック、膝盾を差したら潰し直し、腰角度を切られたら肘を中心線へ戻す、のように初動そのものが正解を変えます。
回答結果は `rollState` として次局面へ引き継がれます。たとえば「ガード回復」が残っていると、サイド攻撃では通常のマウント移行ではなく、戻された膝を潰し直す選択肢が出ます。各 scenario の `stateBias` に一致する状態は次局面候補と時間切れ時の追撃候補も少し出やすくするため、正解/不正解は単発で終わらず、次の局面の選択肢と展開そのものに影響します。

3 つのフォーカスを切り替えて学べます。

- **混合ロール**: 防御局面と攻撃局面を毎回ランダムに組み合わせ、攻守の判断を続ける。
- **防御ロール（自分＝青）**: バックを取られた → マウントされた → サイドで抑えられた、と
  「まず生き残る」連鎖。守って局面を引き戻す。
- **攻撃ロール（自分＝赤）**: マウント／バック／サイドから、良い位置を作ってから極める。
  **position before submission** を手を動かしながら体感する。

各ロールには **今回の狙い** がランダムに付きます。例: 「安全第一」「守って攻めへ」「反応を追う」。
達成すると終了時にボーナスポイントが入り、同じシナリオ列でも練習の焦点が変わります。
さらに **今回の制約** も付きます。例: 「生存優先」「位置を上げる」「極めの連鎖」「速いスクランブル」。
制約は表示だけでなく、出やすい局面、実戦時の判断時間、次局面の重みに効くため、同じ局面でもロールのテンポと展開が変わります。
前回ロールでミスや時間切れがあった場合、通常の再ロールではそのときの `readCues` を一つ拾い、
関連する局面が少し出やすくなります。固定問題集にはせず、苦手局面を直接反復したい場合は別ボタンの「苦手局面から再ロール」を使います。

さらに **ギ／ノーギ** を切り替えると、見た目（襟・帯 vs ラッシュガード）と
一部の判断内容（ギ＝襟防御、ノーギ＝手首/前腕のハンドファイト）が変わります。
**入門／実戦** の難易度切替では、入門は時間制限なしで読みを練習し、実戦だけ判断時間と時間切れ結果が有効になります。
ロールごとに相手スタイル（ランダム／プレッシャーパサー／絞めハンター／ガードプレイヤー）も選べ、
出やすい局面、相手の初動、正解後の次局面、実戦モードの相手意図が少し変わります。
ガードプレイヤー相手では、下からの腕十字/三角だけでなく、クローズドガード内で姿勢を守ってパスする局面も出やすくなります。
相手の初動後、速く正解できた場合は **テンポ評価** が付き、小さなボーナスが入ります。
正解/不正解/実戦での時間切れで **流れ**（優勢・前進・五分・危険・劣勢）が変わり、
実戦モードでは流れに応じて次局面の判断時間も少し変化します。混合ロールでは、
優勢なら攻め、危険なら守りへ繋がる `next` 候補が少し出やすくなり、終了レビューに分岐理由が残ります。

> 設計思想: 技のコレクションではなく **原則** を学ぶ。
> 柔術指導の背骨である **ポジション階層** と **position before submission**、
> そして「**タップは負けでなく学び・安全装置**」という安全文化を中心に据えています。

## 実行方法

ES Modules + CDN の Three.js を使うため、**静的サーバー経由**で開く必要があります（`file://` 直開きは不可）。

```sh
cd Jiu-Jitsu
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

> 任意の静的サーバーで可（`npx serve`, `php -S localhost:8080` など）。
> 初回は CDN (jsDelivr) から Three.js を取得するためネット接続が必要です。

ローカル検証:

```sh
for f in js/*.js; do node --check "$f"; done
node scripts/validate-data.mjs
node scripts/validate-game-logic.mjs
```

## 操作

| 操作 | 効果 |
|------|------|
| ドラッグ | カメラ回転（初期状態では固定） |
| ホイール / ピンチ | ズーム |
| 選択肢クリック / 数字キー 1〜4 | 相手の初動後に一手を選ぶ |
| 回答後 Enter | 次の局面へ進む |
| 回答後 R | 同じ局面を復習 |
| 混合 / 防御 / 攻撃 トグル | ロールフォーカスを切り替える |
| ギ / ノーギ トグル | 道着とラッシュガードを切り替える |
| 入門 / 実戦 トグル | 入門=時間制限なし、実戦=判断時間あり |
| ランダム / 圧 / 絞め / ガード トグル | 相手スタイルを切り替える（初期値はランダム） |
| 「この局面をもう一度」 | 同じ局面を復習（間違えた手の反復に） |
| 「道場の心得」 | ポジション階層・原則・用語・**研究の裏付け** を開閉 |

各局面はまず構えを見せ、相手の初動が出てから選択肢が有効になります。入門では時間制限なしで考えられます。実戦では**判断の制限時間**があり、迷っていると相手が動いてサブミッションへ進みます
（柔術の「考えている間に極められる」感覚の再現）。正解で道場ポイント、連続正解と速い正解でボーナス、
ロールごとの狙い達成でもボーナス、
累計正解数に応じて **白 → 青 → 紫 → 茶 → 黒** と帯が上がります。
リプレイは復習用で、同じ局面を解き直しても点数・連続正解・テンポボーナス・流れは二重に変化しません。
ロール終了時にミスや時間切れがあった場合は、最初の苦手局面と同じ相手初動から始める再ロールも選べます。
開発時のUI確認には `_ui_audit.html` を使えます。3Dを起動せず、setup中の選択肢ロック、判断フェーズの番号表示、初動別に正解が変わる表示を並べて確認できます。

## カリキュラム（3 つのフォーカス）

柔術を最初に習うときの順序＝「まず下から生き残る」、そして「上を取ったら良い位置から極める」
を、混合/防御/攻撃のフォーカスで反復します。

**混合ロール**

防御局面と攻撃局面から 4〜5 局面を毎回ランダムに構成します。固定問題集ではなく、
その回に出た相手の動きと、実戦では制限時間に合わせて判断します。

**防御ロール（自分＝青）**

1. **バックディフェンス** — 裸絞め（マタレオン）に対し、まず首を守る → 弱い側へ脱出。
2. **マウント脱出** — 腕隔離にはアッパ、腰を伸ばす脚絡みには膝肘エスケープ。腕を伸ばして押すと腕十字を取られる。
3. **サイドコントロール脱出** — フレーム＋海老（シュリンプ）でガードリカバリ。
4. **クローズドガード内の姿勢防御** — 頭・肘・腰の線を守り、下からの腕十字/三角を消してパスへ。

**攻撃ロール（自分＝赤）**

1. **マウントからの攻め** — ベースを保ち、肘を隔離してから腕十字へ。
2. **バックからの攻め** — シートベルトを保ち、防御手を一枚ずつ剥がしてから絞めへ。
3. **サイドからの前進** — フレームを潰し腰を制し、ニーオンベリー→マウントへ階層を登る。
4. **ガードからの腕十字** — 姿勢を崩し、肘を中心線から外して脚を回す。
5. **三角絞めへの連携** — 片腕を内側に残し、角度を作って首と肩を閉じる。

各局面は `js/techniques.js` に `SCENARIOS`（防御）/ `OFFENSE_SCENARIOS`（攻撃）として定義。
`setup → attack（決断の瞬間）→ choice → result → reaction/consequence → next` の流れを 3D と UI で実演します。
局面ごとに `opponentActions` と `readCues`（読む線）を持ち、首・肘・腰・フレームなど観察すべき力関係を短いチップで示します。各 `opponentActions` は専用の attack ポーズと cue も持つため、判断フェーズで相手の初動が視覚的にも変わり、回答後には「初動の読み」として復習できます。一部の攻防局面では `requiresAction` / `forbiddenAction` により、初動に応じて表示される正解選択肢も変わります。
回答後には、その初動で見るべき `readCues` を「読めた線 / 見落とした線」として返し、
ロール終了時には、その回の選択・正誤・読む線・テンポ・相手の反応/追撃・実際に繋がった次局面・原則・今回の狙い達成状況・今回の制約・次の稽古ポイントをレビュー表示します。
ミスがあれば「苦手局面から再ロール」で、その局面と相手初動を先頭にした新しいロールへ入れます。

## 技術構成

ビルド不要・依存はランタイムの Three.js（CDN）のみ。

| ファイル | 役割 |
|----------|------|
| `index.html` / `css/style.css` | レイアウトと UI（混合/防御/攻撃、ギ/ノーギ、入門/実戦、相手スタイル） |
| `js/fighter.js` | プリミティブで組んだヒューマノイドの関節リグ。テーパー四肢・造形した胴／頭／手足、ギ／ノーギ描画切替。クォータニオン補間でポーズ遷移 |
| `js/poses.js` | 各ポジション（マウント／バック／サイド／ガード等）を関節角度データで定義。寝技は仰向け＝腹が上、上の人＝膝立ちで噛み合わせる座標規約 |
| `js/poseSpecs.js` | 各ポーズの役割、支持基底、接触点、力の方向を定義。`_audit` と検証スクリプトで重心・荷重・力関係の仕様漏れを検出 |
| `js/positionCatalog.js` | 全BJJの主要ポジションファミリー、実装済み pose role、許可された赤/青 role ペアを定義。未実装ポジションがゲームに混ざらないよう検証する |
| `js/scene.js` | Three.js のシーン・畳・ライト・カメラ操作、ギ／ノーギの一括切替 |
| `js/techniques.js` | 教育コンテンツ（防御 `SCENARIOS` ／攻撃 `OFFENSE_SCENARIOS` ・相手初動 `opponentActions` と専用 attack pose・選択肢・解説・道場の心得・研究の裏付け） |
| `js/game.js` | 状態機械（連続ロール進行・相手初動の重み付き選択・初動別の選択肢出し分け・苦手局面からの再ロール・前回ミスした readCue による軽い適応補正・正解/不正解の重み付き `next` 候補による次局面差し替え・`rollState` / `stateBias` による選択肢出し分けと次局面重み補正・実戦時間切れ時の相手スタイル/流れ/状態に沿う悪手選択・ロールミッション・戦術制約・自動前進・採点・連続正解/実戦テンポボーナス・流れメーター・実戦判断制限時間補正・帯昇格・ギ／ノーギ別の選択肢出し分け・回答履歴） |
| `js/ui.js` | DOM レンダリング層（局面、今回の狙い、今回の制約、読む線、読めた/見落とした線、相手の反応/追撃つきフィードバック、流れ表示、次局面と理由・次の稽古つきロール終了レビュー） |
| `js/main.js` | 起動エントリ |

人体は解剖学的厳密さより「どのポジションか読み取れる」ことを優先したスタイライズです。方向・上下関係は改善済みですが、物理シミュレーションではないため、重心・接触・力関係は `positionCatalog.js` の分類制約、`poseSpecs.js` の身体制約仕様、`validate-data` の関節角レンジ/root 座標/ペア距離/高さ関係/向き関係/支持中心/相手へ荷重する力ベクトル/明示許可 role ペアのチェック、スクショ駆動で検証します。膝は簡易リグではヒンジとして扱い、`shinL` / `shinR` の負方向屈曲は禁止します。脚を開く・腰を囲む・三角で角度を切る表現は股関節と root 回転で作ります。`fighter.js` は `anatomy.js` の同じ関節制約でレンダリング時にも角度を clamp し、床付近の pose は floor probe で root 高さを小さく補正します。詳細は [docs/HUMAN_BODY_MODEL.md](docs/HUMAN_BODY_MODEL.md)。`_audit.html` は既定で重心投影、支持エリア、支持中心起点の力ベクトル、相手への荷重線、接触点ラベルを表示し、`markers=off` で非表示にできます。現状は、バックの背後関係、サイドの胸圧、マウントの骨盤位置と前傾、クローズドガード上側のベース、ガード腕十字/三角で捕まる側の姿勢崩しと脚の捕獲感を再調整済みです。腕十字の肘支点、三角の膝裏/足首ロック、細かい接触は継続調整対象です。

## 教育設計の根拠（英語文献・最新研究）

ゲーム内の主張は以下の研究・文献に基づいています。要点はゲーム内「道場の心得 ▸ 研究の裏付け」にも収録。

- **ポジション優先は上半身の技でこそ成立**: 競技 no-gi の動作分析で、位置の優位は上半身サブミッション（絞め・腕関節）と相関（r = 0.50, p < 0.05）。一方ヒールフック等の下半身関節技は位置支配なしでも決まる例が多い — 本ゲームが扱う上半身の攻防は原則が効く領域。
  Spanias et al. (2022) *Position before submission? Techniques and tactics in competitive no-gi Brazilian jiu-jitsu*, Revista de Artes Marciales Asiáticas — [journal](https://revistas.unileon.es/index.php/artesmarciales/article/view/7410) / [full text PDF](https://shura.shu.ac.uk/31193/1/Spanias%20et%20al%202022%20BJJ%20Time%20Motion%20Analysis.pdf)
- **腕十字は最多の受傷機転**: 競技傷害の整形外科的傷害の 38.9% が肘、その肘傷害 14 例中 10 例が腕十字。「肘を隠す・伸ばさせない」が安全面でも最重要。傷害率は約 9.2/1000 exposure で MMA・柔道より大幅に低い。早期タップが傷害予防の第一。
  Scoggin et al. (2014) *Assessment of Injuries During Brazilian Jiu-Jitsu Competition* — [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4555620/)
- **教育ツールとしての効果**: 学校での BJJ プログラム RCT で児童の認知的自己制御・教室行動の改善が報告。意思決定・問題解決・レジリエンス育成への寄与が学術的に検討されている。
  *Effects of a school-based Brazilian jiu-jitsu programme on mental health and classroom behaviour of children from Abu Dhabi: a randomised trial* (2022) — [ResearchGate](https://www.researchgate.net/publication/362664907) ／ *The role of Brazilian jiu-jitsu in holistic education* (2025), The American Journal of Applied Sciences — [link](https://theamericanjournals.com/index.php/tajas/article/view/5885)
- **現代の指導法（Constraints-Led Approach / 生態学的ダイナミクス）**: 孤立した型反復より、制約を与えた状況で解を自ら発見させる方が技能の定着・転移・創造的問題解決に優れるとされ、2020 年代の柔術指導の潮流。本ゲームの「状況 → 判断」形式はこの思想に沿う。
  *Applying an ecological dynamics framework to mixed martial arts training* (2024), Sports Coaching Review — [Taylor & Francis](https://www.tandfonline.com/doi/full/10.1080/21640629.2024.2325822)

### 用語の出自について

「柔術（じゅうじゅつ）」は日本古来の徒手武術で、地上での関節技・絞めを体系化したもの。
20 世紀初頭に前田光世らによってブラジルへ伝わり、グレイシー一族らが地上戦を発展させて
**ブラジリアン柔術（BJJ）** となりました。本ゲームの技名は日本語（柔道・古流由来）と
ポルトガル語（BJJ 由来）を併記しています（例: 十字固め / juji-gatame、裸絞め / mata-leão）。
