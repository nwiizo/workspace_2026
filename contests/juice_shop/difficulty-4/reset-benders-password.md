# Reset Bender's Password ✅

**難易度:** ⭐⭐⭐⭐
**カテゴリ:** OSINT
**目標:** セキュリティ質問の答えを推測してパスワードをリセット

---

## 実行手順

1. `http://localhost:3000/#/forgot-password` にアクセス
2. Email: `bender@juice-sh.op`
3. 質問: "Company you first worked for as an adult?"
4. 答え: `Stop'n'Drop`

## 解説

**背景情報:**
- Bender は Futurama というアニメのキャラクター
- Stop'n'Drop は作中に登場する会社名
- キャラクターの背景を調べることで答えがわかる

**Futurama とは:**
- Matt Groening（シンプソンズの作者）による SF アニメ
- Bender = 飲酒癖のあるロボット
- 作中の設定を調べることで解答可能
