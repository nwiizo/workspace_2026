# Poison Null Byte ✅

**難易度:** ⭐⭐⭐⭐
**カテゴリ:** バイパス
**目標:** 本来ダウンロードできないファイルを取得する

---

## 思考プロセス

**ステップ1: ファイルダウンロード制限を確認**
```
「/ftp ディレクトリにファイル一覧がある」
    ↓
「.md や .pdf は普通にダウンロードできる」
    ↓
「.bak（バックアップファイル）をクリックすると...」
    ↓
「403 Forbidden！拡張子でフィルタリングされている」
```

**ステップ2: バイパス方法を考える**
```
「サーバーはどうやって拡張子を確認している？」
    ↓
「ファイル名の末尾を見ているはず」
    ↓
「.bak.md にすれば .md として許可される？」
    ↓
「でも実際のファイル名と違うからエラーになる」
    ↓
「ファイル名の途中を切り捨てる方法はないか...」
```

**ステップ3: Null Byte インジェクション**
```
「Null文字（%00）は文字列の終端を意味する」
    ↓
「多くの言語（C言語など）でNull以降は無視される」
    ↓
「package.json.bak%00.md を送信」
    ↓
「サーバー側の拡張子チェック: 末尾が .md → OK!」
    ↓
「ファイル読み込み時: %00 で切れて .bak を返す」
```

## 実行手順

ブラウザで以下にアクセス:
```
http://localhost:3000/ftp/package.json.bak%2500.md
```

## 解説

**%2500 とは？**
- `%00` = NULL文字
- `%2500` = `%00` をURLエンコードしたもの（ダブルエンコード）
- ブラウザ: `%2500` → `%00`
- サーバー: `%00` → NULL文字

**なぜダブルエンコードが必要？**
- `%00` を直接送信すると、ブラウザがデコードしてしまう
- `%2500` にダブルエンコードすることで回避
