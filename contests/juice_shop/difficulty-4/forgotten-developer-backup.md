# Forgotten Developer Backup ✅

**難易度:** ⭐⭐⭐⭐
**カテゴリ:** 情報漏洩
**目標:** バックアップファイルをダウンロードする

---

## 実行手順

ブラウザで以下にアクセス:
```
http://localhost:3000/ftp/package.json.bak%2500.md
```

## 解説

- `package.json.bak` にはアプリケーションの依存関係やスクリプトが含まれる
- バックアップファイルが残されていると、攻撃者に情報を与えてしまう
- Poison Null Byte を使ってファイル拡張子チェックをバイパス

**バックアップファイルの危険性:**
- 設定ファイル（パスワード、APIキー）
- 古いバージョンのコード（既知の脆弱性）
- データベースダンプ（個人情報）

**対策:**
- 本番環境にバックアップファイルを置かない
- `.bak`, `.old`, `.backup` などの拡張子をブロック
- ファイルシステムの定期監査
