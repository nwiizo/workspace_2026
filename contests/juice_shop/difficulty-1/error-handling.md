# Error Handling ✅

**難易度:** ⭐
**カテゴリ:** 情報漏洩
**目標:** エラーメッセージを表示させる

---

## 実行手順

1. `http://localhost:3000/#/login` にアクセス
2. Email欄に `'` （シングルクォート1つ）を入力
3. Password欄に何か入力
4. Login ボタンをクリック
5. SQLエラーメッセージが表示されれば成功

## 解説

- エラーメッセージにデータベースの詳細情報が含まれている
- 攻撃者にシステムの構造を教えてしまう危険性がある

**漏洩する情報の例:**
- データベースの種類（SQLite, MySQL など）
- テーブル名やカラム名
- SQLクエリの構造
- 内部パス情報

**教訓:**
- 本番環境では詳細なエラーメッセージを表示しない
- ユーザーには「エラーが発生しました」のような汎用メッセージを表示
- 詳細はログに記録し、開発者だけがアクセスできるようにする
