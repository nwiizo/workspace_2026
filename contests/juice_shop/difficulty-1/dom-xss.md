# DOM XSS ✅

**難易度:** ⭐
**カテゴリ:** XSS
**目標:** 検索欄にスクリプトを注入してアラートを表示させる

---

## 思考プロセス

**ステップ1: 入力が表示される場所を探す**
```
「検索欄に文字を入力すると...」
    ↓
「検索結果ページに "〇〇 の検索結果" と表示される」
    ↓
「入力値がそのままHTMLに挿入されている？」
    ↓
「HTMLタグを入れたらどうなる？」
```

**ステップ2: 簡単なHTMLタグでテスト**
```
「<b>test</b> を入力してみる」
    ↓
「"test" が太字で表示された！」
    ↓
「HTMLが解釈されている = XSSの可能性あり」
```

**ステップ3: スクリプト実行を試す**
```
「<script>alert('xss')</script> を試す」
    ↓
「動かない... Angularがブロックしている」
    ↓
「別の方法を試す: <iframe src="javascript:...">」
    ↓
「アラートが表示された！」
```

## 実行手順

1. Juice Shop のトップページを開く
2. 右上の検索アイコン（虫眼鏡）をクリック
3. 検索欄に以下をコピー＆ペースト:
   ```html
   <iframe src="javascript:alert('xss')">
   ```
4. Enter を押す
5. 「xss」というアラートが表示されれば成功

## 解説

**なぜこれが危険？**
- 攻撃者がこの脆弱性を使って、ユーザーのCookieを盗んだり、偽のログインフォームを表示できる
- XSS = Cross-Site Scripting（クロスサイトスクリプティング）
