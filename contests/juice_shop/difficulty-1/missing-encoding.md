# Missing Encoding ✅

**難易度:** ⭐
**カテゴリ:** エンコード
**目標:** 表示されない画像を正しく表示させる

---

## 実行手順

1. `http://localhost:3000/#/photo-wall` にアクセス
2. 壊れた画像（表示されない画像）を見つける
3. その画像を右クリック → 「画像アドレスをコピー」
4. URLに `#` が含まれていることを確認
5. `#` を `%23` に置き換えたURLをアドレスバーに入力:
   ```
   http://localhost:3000/assets/public/images/uploads/😼-%23zatschi-%23whoneedsfourlegs-1572600969477.jpg
   ```
6. 猫の画像が表示されれば成功

## 解説

- `#` はURLで特別な意味を持つ文字（アンカーリンク）
- `%23` は `#` をURLエンコードしたもの
- 特殊文字はエンコードしないと正しく処理されない

**URLエンコードの例:**
| 文字 | エンコード |
|------|-----------|
| `#` | `%23` |
| ` ` (空白) | `%20` |
| `&` | `%26` |
| `?` | `%3F` |
