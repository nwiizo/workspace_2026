# Confidential Document ✅

**難易度:** ⭐
**カテゴリ:** 情報漏洩
**目標:** 機密文書をダウンロードする

---

## 思考プロセス

**ステップ1: 隠しディレクトリを探す**
```
「Webサイトには見えない部分がある」
    ↓
「よくあるディレクトリ名を試す」
    ↓
「/admin, /backup, /ftp, /files, /uploads...」
    ↓
「/ftp でファイル一覧が表示された！」
```

**ステップ2: ディレクトリリスティングとは？**
```
「本来はファイル一覧を見せるべきではない」
    ↓
「サーバーの設定ミスで有効になっている」
    ↓
「攻撃者は機密ファイルを発見できてしまう」
```

**ステップ3: 興味深いファイルを探す**
```
「acquisitions.md = 買収情報（機密！）」
    ↓
「package.json.bak = バックアップファイル」
    ↓
「クリックしてダウンロード」
```

## 実行手順

1. ブラウザのアドレスバーに以下を入力:
   ```
   http://localhost:3000/ftp
   ```
2. ファイル一覧が表示される
3. `acquisitions.md` をクリックしてダウンロード
4. ファイルが開けば成功

## 解説

**なぜこれが危険？**
- 本来は公開されるべきでない内部文書にアクセスできてしまう
- ディレクトリリスティングが有効になっている設定ミス
