# Score Board ✅

**難易度:** ⭐
**カテゴリ:** 隠蔽
**目標:** 隠されたスコアボードページを見つける

---

## 思考プロセス

**ステップ1: 隠しページの存在を予測**
```
「CTFにはスコアボードがあるはず」
    ↓
「でもメニューには見当たらない」
    ↓
「URLを直接入力すればアクセスできるかも？」
```

**ステップ2: URLを推測**
```
「よくあるURL名を試す」
    ↓
「/scoreboard, /score-board, /admin, /dashboard...」
    ↓
「/#/score-board でヒット！」
```

**ステップ3: なぜこれが見つかる？**
```
「main.js（JavaScriptのソースコード）にルート情報がある」
    ↓
「DevTools → Sources → main.js で検索可能」
    ↓
「"score" や "board" で検索すると発見できる」
```

## 実行手順

1. ブラウザで Juice Shop を開く
2. アドレスバーに以下を入力して Enter:
   ```
   http://localhost:3000/#/score-board
   ```
3. スコアボードが表示されれば成功

## 解説

**なぜこれが脆弱性？**
- 本来は隠されているべきページが、URLを知っていれば誰でもアクセスできる
- これを「Security through Obscurity（隠蔽によるセキュリティ）」の失敗と呼ぶ
