# Five-Star Feedback ✅

**難易度:** ⭐⭐
**カテゴリ:** アクセス制御
**目標:** 5つ星のフィードバックを削除する

---

## 思考プロセス

**ステップ1: 管理者としてログイン**
```
「フィードバックを削除するには管理者権限が必要」
    ↓
「SQLi で管理者としてログイン: ' OR 1=1--」
    ↓
「最初のユーザー（admin）としてログイン成功」
```

**ステップ2: 管理画面を探す**
```
「管理者なら管理画面があるはず」
    ↓
「main.js で "admin" を検索」
    ↓
「/#/administration というルートを発見」
    ↓
「アクセスすると管理画面が表示される」
```

**ステップ3: フィードバックを削除**
```
「Customer Feedback セクションを確認」
    ↓
「5つ星のフィードバックを見つける」
    ↓
「ゴミ箱アイコンをクリックして削除」
    ↓
「管理者権限の悪用成功！」
```

## 実行手順

1. 管理者でログイン（SQLi: `' OR 1=1--`）
2. アドレスバーに: `http://localhost:3000/#/administration`
3. Customer Feedback セクションを見つける
4. 5つ星（★★★★★）のフィードバックのゴミ箱アイコンをクリック

## 解説

- 管理者権限があれば、ユーザーのフィードバックを削除できる
- これはビジネス上のリスク（良い評価を消されると困る）
- 権限の分離と監査ログの重要性
