# Visual Geo Stalking ✅

**難易度:** ⭐⭐
**カテゴリ:** OSINT
**目標:** 写真の背景に写っているロゴから会社名を特定

---

## 思考プロセス

**ステップ1: 写真を詳しく観察**
```
「Emma の写真を見る」
    ↓
「本人だけでなく、背景にも注目」
    ↓
「何か文字やロゴが写っていないか？」
```

**ステップ2: ロゴを発見**
```
「背景に "ITsec" というロゴが見える！」
    ↓
「これは Emma の勤務先らしい」
    ↓
「セキュリティ質問に使える情報かも」
```

**ステップ3: パスワードリセット**
```
「質問: 最初の勤務先は？」
    ↓
「写真の背景から ITsec と判明」
    ↓
「パスワードリセット成功」
```

## 実行手順

1. `/#/photo-wall` で Emma（E=ma²）の写真を確認
2. 背景に「**ITsec**」というロゴが見える
3. `/#/forgot-password` でメール `emma@juice-sh.op` を入力
4. セキュリティ質問: "Company you first work for as an adult?"
5. 答え: `ITsec`

## 解説

**教訓:**
```
「SNSの写真から個人情報が特定される」
    ↓
「背景に写り込む会社名、住所、名札など」
    ↓
「写真をアップする前に背景をチェックしよう」
```

**視覚的OSINTの例:**
- 窓の外の風景から住所を特定
- 机の上の書類から機密情報を読み取る
- 社員証や名札から氏名・部署を特定
- 背景のカレンダーから日付を特定
