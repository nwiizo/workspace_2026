# Challenge Documentation Rules

チャレンジを解いたら必ず以下を行う:

## 1. 解説ファイル作成

- **場所:** `difficulty-X/challenge-name.md` (ケバブケース)
- **形式:**

```markdown
# チャレンジ名 ✅

**難易度:** ⭐⭐⭐
**カテゴリ:** SQLi / XSS / 認証 など
**目標:** 具体的なゴール

## 思考プロセス
[なぜこの攻撃が効くのかの考察]

## 実行手順
[再現可能なステップ]

## コード/ペイロード
[攻撃コード]

## 解説
[脆弱性の原因と対策]
```

## 2. 進捗更新

- `difficulty-X/README.md` の進捗表を更新
- ✅ 解決済みリストにチャレンジを追加
- ファイルへのリンクを追記

## 3. result.md 更新

- 全体の解決数を更新
- 難易度別の解決数を更新

## 4. 学びの記録 (任意)

- 新しい攻撃手法は `attack-techniques.md` に追記
