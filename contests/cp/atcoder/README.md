https://atcoder.jp

## Contest Types

| Type | Description | Difficulty |
|------|-------------|------------|
| ABC | AtCoder Beginner Contest | 灰〜青 |
| ARC | AtCoder Regular Contest | 緑〜橙 |
| AGC | AtCoder Grand Contest | 水〜赤 |

## Setup

```bash
# cargo-compete
cargo compete init atcoder
cargo compete new abc300
cargo compete test a
cargo compete submit a
```
