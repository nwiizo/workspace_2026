# Competitive Programming

競技プログラミングのコンテスト・問題集

## Platforms

| Directory | Platform | URL |
|-----------|----------|-----|
| `atcoder/` | AtCoder | https://atcoder.jp |
| `codeforces/` | Codeforces | https://codeforces.com |
| `leetcode/` | LeetCode | https://leetcode.com |
| `aoj/` | Aizu Online Judge | https://judge.u-aizu.ac.jp |
| `yukicoder/` | yukicoder | https://yukicoder.me |

## Directory Structure

```
cp/
├── atcoder/
│   ├── abc300/          # AtCoder Beginner Contest 300
│   │   ├── a.rs
│   │   ├── b.rs
│   │   └── ...
│   ├── arc180/          # AtCoder Regular Contest 180
│   └── typical90/       # 競プロ典型90問
├── codeforces/
│   └── round900/
├── leetcode/
│   ├── daily/           # Daily Challenge
│   └── contests/        # Weekly/Biweekly Contest
├── aoj/
│   └── courses/         # AOJ Courses
└── yukicoder/
    └── contests/
```

## Naming Convention

- AtCoder: `abc300`, `arc180`, `agc060`, `typical90`
- Codeforces: `round900`, `div2_900`, `edu160`
- LeetCode: `weekly380`, `biweekly120`, `daily`
