# 採点と模擬審査

採点を求められた場合に使う。応募文の作成や通常の改善へ一律に追加しない。
募集側の公開基準があればそれを優先し、なければ次を編集上の尺度として使う。

| 点 | 判断 |
| --- | --- |
| 5 | 価値と根拠が明確で、目立つ欠落がない |
| 4 | 小さな修正で判断しやすくなる |
| 3 | 重要な説明や差別化が不足する |
| 2 | 方向性はあるが大きな修正が必要 |
| 1 | 基本的な条件や主張の根拠が不足する |

SKILL.mdの評価観点ごとに、点数と原文の根拠を結びつける。
項目別の点数だけで足りるなら合計しない。総合点を求められた場合は集計方法を示す。
制約違反と事実の問題は、他項目の点数で相殺しない。

模擬審査の依頼では「採択推奨」「修正を条件に検討」「不採択」の判断と理由を示せる。
これは提示資料と公開基準に基づく模擬判断であり、実際の採択見込みの測定ではない。
馴染みのある企業・技術・話者への好感を、内容の根拠に置き換えない。
個人的に参加したいかは、その観点を求められた場合だけ区別して述べる。
